# Login and Logout Feature - Session Export

**Date:** 2026-06-08  
**Branch:** feature/login-logout (merged to main)

---

## Overview

User login and logout functionality that allows registered users to authenticate and access their account. Login verifies email and password credentials, then starts a session. Logout clears the session and redirects to the landing page.

---

## Depends on

- Step 2: Registration (users table exists, users can register)

## Routes

- `POST /login` — Process login credentials — public
- `GET /logout` — Clear session and redirect — logged-in only

## Implementation Details

### 1. Database Helper (`database/db.py`)

Added `get_user_by_email(email)` function:
- Queries users table by email using parameterized query
- Returns user row (with id, name, email, password, created_at)
- Returns None if not found

### 2. Login Handler (`app.py`)

- Added imports: `session`, `check_password_hash`
- GET: renders `login.html`
- POST:
  - Validates email and password fields not empty
  - Calls `get_user_by_email(email)`
  - If user not found → renders login.html with error "Invalid email or password"
  - Uses `check_password_hash(user['password'], password)` for verification
  - If password invalid → renders login.html with error
  - If password valid → sets session variables, flashes success message, redirects to landing page

### 3. Logout Handler (`app.py`)

- Clears session with `session.clear()`
- Flashes message "You have been signed out."
- Redirects to landing page

### 4. Login Template (`templates/login.html`)

- Changed form action from `/login` to `{{ url_for('login') }}`
- Added flash message display for success messages

### 5. Base Navigation (`templates/base.html`)

- Added conditional navigation based on login status
- When logged in: shows "Hello, {name}", Profile link, Sign out link
- When logged out: shows Sign in, Get started links

## Session Variables

- `session['user_id']` - User's ID
- `session['user_name']` - User's name
- `session['user_email']` - User's email
